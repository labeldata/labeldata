{% comment %} '배합에서 계산' 단추의 동작. 이 화면의 흐름은 이미 세 걸음이다 — 계산값 → 오차 → 적용값. 이 단추가 하는 일은 **첫 걸음의 값을 채우는 것뿐**이다. 배합 쪽에서 오차까지 물려 오면 여기서 다시 물려 두 번 곱해진다(계산기가 겪은 사고가 그것이다: 309 를 두 번 저장해 475 가 되고 731 이 됐다). 계산이 막히면 값을 채우지 않고 **왜 막혔는지**를 말한다. 빈 값을 0 으로 채워 넣으면 그럴듯하고 틀린 표가 만들어진다. 탭이 iframe 으로 갈려 있어 배합 탭에서 고친 것이 여기로 자동으로 오지 않는다. 그래서 단추를 누를 때마다 **서버에 다시 묻는다** — 화면에 값을 들고 있다가 쓰면 배합을 고친 뒤에도 옛 값을 넣게 된다. {% endcomment %}
